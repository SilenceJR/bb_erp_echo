# Astra 客户端设计：精密工作台

2026-09-05。最新设计由 Astra 制定；用户已确认中性灰白、精密克制和均衡密度。本文是本轮视觉实现依据，取代旧版外观约束；业务、权限、数据保护及 Web/Tauri 共用约束保持。

## 整体构成

### 全产品覆盖与内容准则

用户确认本轮是全产品翻新，而非局部换肤。旧前端结构、组件、样式与版本兼容不构成保留条件。启动、服务发现/选择/失败恢复、登录、会话失效、主框架、首页、全部业务和系统模块、设置、更新、图片文件、浮层与反馈均须重新设计。业务权限、账号规则、数据保护与模块过渡契约保持。

逐流程验收：进入应用→连接→登录→查找业务→筛选与选择→查看与编辑→提交反馈→返回继续工作；另测取消、错误恢复、未保存与无权限。所有入口逐项记录，未覆盖项保持未完成，不以客户页样板代表全套交付。

文案说明真实功能、当前结果、限制及可采取动作；删除开发/验收术语和设计自述。不用静态导航冒充今日关注，不以入口数量/账号类型充当经营指标，不制造待办或图表占位。首页保留一组真实入口；统计只显示来源可用且有业务意义的内容，没有内容允许留白。不可用集中说明，不当真实零值；精简不得牺牲错误原因、操作后果或单位。

中央采用连续数据工作面：标题、业务 Tab、筛选、结果说明、表格、分页通过水平分区组织，不分别套卡片。取消一级业务页“首页 / 当前页”重复面包屑，保留顶栏定位和唯一 H1。右侧使用对象档案式分组属性，取消灰底标签网格。

- 原生窗口标题“博邦 ERP”；应用顶栏 56px。导航品牌区同高，logo 28px。
- 导航 224/64/0px，项高 40px、间距 2px、图标18px、文字14px/500，选中600、2px品牌定位线与浅底；分组间16px。设置固定在底部，中间独立滚动；移除无动作帮助占位。
- 中央背景 surface，左右24px；1024使用20px、768以下16px。数据页流式宽度，长说明单独限制阅读宽度。
- 页面标题24/32px、600，说明13/20px最长两行，标题区上下20px；操作对齐首行。中央有效宽度不足800px时导入导出可归入权限感知的资料操作菜单，创建保持可见。
- Tab44px、活动线2px、项间24px；筛选上下12px、控件40px、组间16px，无卡片边框；结果说明32px、13px，总数只出现一次。
- 长列表使用可控的表格滚动区与固定分页，避免多重纵向滚动；短列表真实行之后保留连续工作面，不生成假行。

## 对象详情与设置

详情标准420px、图片520px。停靠无圆角/阴影，以1px线分隔；头/正文/底栏三段布局，左右24px，底栏最小72px，正文最后24px安全空间。创建/编辑单列，正文宽达到560px才可双列；字段间18px，标签13/20px、下距6px。

对象编码12–13px，主名20/28px/600、可两行，全称13/20px；避免重复名称。分区标题14px/600，分区间24px。属性采用 `dl` 等语义结构，标签84px（必要时96px）、间隔16px、值 `minmax(0,1fr)`，行最小36px，长地址自然换行。资料空值“未填写”；统计不可用值必须带来源说明。

客户分“基本资料 / 联系信息 / 同编码资料”，同码对象项最小60px，浅选中底和品牌线，仅一条也不称“其他资料”。查看态突出编辑，设默认/删除放更多菜单，危险项单独分组。编辑态取消左、保存右；保留提交硬锁和未保存守卫。

按用户最新统一面板决定，设置覆盖面板520px、窄屏自适应，只有“外观 / 连接与服务”分区，移除重复眉题。亮暗采用40px分段选择，直接切换真实界面，不额外占用92px微缩预览；品牌色三项56px高，色点16px+名称+勾。连接属性标签96px，状态位于分区标题右侧，地址可换行。

## 动效、焦点和响应式

正文14/22px，辅助/标签/表头13/20px，关键字重600；数字tabular-nums，电话不强制粗体。控件120ms、Tab160ms、栏宽180ms，缓动cubic-bezier(.2,0,0,1)。详情最多6px/180ms，刷新不整页动画；reduced-motion移除位移/缩放；Teleport不使用初始opacity:0或AnimatePresence。

查看停靠保留列表焦点，编辑/新增进入首个可编辑字段；覆盖Drawer由组件管理焦点。Escape先关闭顶层浮层，不能穿透关闭两层。关闭恢复触发点，无触发点时回归合理列表入口。

停靠条件：viewport>=1440，并且 `viewport-sidebar-detail-分隔线-中央左右内边距>=720`。1440全左栏420详情可停靠，520图片详情需更宽；full/icon/hidden均按真实宽度计算。断点不得重置表单、挂载双份或丢失用户编辑状态。

验收1024×680、1280、1440、1920及1439/1440/1441与图片断点两侧；六种外观组合、真实长文本/空值/多行记录、设置固定可达、底部字段完整。所有模块逐页接入，不以客户页完成代表全套。静态、浏览器、Tauri启动、原生已认证流程与Windows/WebView2分别记录。
