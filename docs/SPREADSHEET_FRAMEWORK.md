# 可扩展表格导入导出框架

`internal/spreadsheet` 将文件格式能力和具体业务规则分离，供未来供应商、产品等资料复用。

## 核心接口

- `WorkbookReader`：把首个工作表读取为统一字符串行；当前注册 `.xls` BIFF8 和 `.xlsx`，其中 `.xlsx` 使用行迭代器并在达到行列上限时立即终止。
- `WorkbookWriter`：把标准文档写为文件；当前正式写出为 `.xlsx`。
- `SheetSchema[T]`：声明列、解码、编码和单元格校验。
- `ImportHandler[T]`：由业务模块实现预览和事务提交。
- `ExportHandler[T]`：按范围、关键词、筛选和分页构建标准文档。
- `FormatRegistry`：按扩展名注册读写适配器，禁止业务 Handler 直接判断具体库。
- `SpreadsheetDocument`：统一标题、列名、列宽、类型、对齐、总数、分页和标准化行。

导出 JSON 预览和最终文件必须从同一个 `SpreadsheetDocument` 生成，不能在前端或下载 Handler 重新拼列。文本类型会以 Excel 文本单元格写出，确保电话和前导零不丢失。

## 新增业务资料的步骤

1. 在业务包内定义固定列和 `SheetSchema`，明确哪些字段是文本。
2. 实现业务自己的 `ImportHandler`：规范化、重复判断、引用关系和事务都留在业务层。
3. 实现 `ExportHandler`，使预览和下载复用同一文档构建逻辑。
4. 注册模块专用路由和权限；不要开放由请求参数任意指定模块的通用导入接口。
5. 增加 `.xls/.xlsx`、文件签名、大小/行数限制、整批回滚、令牌重放及样式测试。

## 安全和一致性约束

- HTTP 上传最多 10 MiB，最多 10,000 条，只处理首个工作表；扩展名和文件签名必须同时匹配。
- 预览令牌只保存摘要并绑定用户、模块和文件 SHA-256，30 分钟过期。
- 确认时重新上传相同文件，令牌条件消费和业务写入必须在同一数据库事务。
- 共享层只处理文件和标准文档；默认资料、编码合并、重复资料及数据库约束由客户业务适配器处理。客户导入批量加载涉及的现有编码与资料快照，在内存完成重复判断和默认规则后分批写入，避免满额导入产生逐行查询。
