## 当前交付边界

本记录是最新 UI 整改的验收基线，优先于旧状态文档中笼统的“已完成/已验收”。代码实现完成不等于 Windows 成品验收完成。本轮不改变后端 API、权限码、账号初始化、已有数据与模块过渡契约。

## 设计及实现基线

- 标准单值输入、选择、日期及按钮外框 40px；表单单列、字段间距 18px；多选多行内容允许自然增高。
- 白色连续工作面、中性灰导航、轻边界；默认博邦蓝亮色，保留暗色、青绿和紫色。统一 hover、focus、disabled 和 loading。
- 一级页取消重复面包屑；筛选、列表与分页连接为数据工作面。无业务价值的计数卡、占位图表和技术文案不作为页面填充。
- 详情 420px，编辑和图片面板 520px，共用 `ResponsiveDetailCarrier`；固定标题和操作栏，正文独立滚动。首帧正文可读。
- 仅在视口至少 1440px 且扣除导航、面板、分隔及中央 48px 内边距后仍有 720px 时停靠。普通详情与表单因宽度不同可能采用不同展示方式；输入、焦点与滚动上下文应保持。
- 查看切换编辑不重复关闭/打开；客户及员工保存回到对应详情。停靠不因中央点击关闭，覆盖遮罩关闭经过未保存保护。
- 同页切换对象、新增、取消、导航、退出与切服均受离开守卫约束；提交中不能丢弃。次级面板覆盖主面板，不并排挤压正文。
- 左栏 224/64/0px，设置固定底部；窄屏为覆盖导航。无缩放、倾斜、整页透明入场；面板 180ms、轻位移不超过 6px，遵守 reduced-motion。

- `go test ./...`：通过；不意味着实际生产库权限矩阵已人工验收。
- Web 类型检查、生产构建及原有 27 项测试通过；终审修复后增加 3 项控制器状态回归测试，当前 30/30 通过。源码/函数级测试不替代实际渲染或真实业务流程。
- 浏览器 15 个模块逐页检查：本次样本下标准控件实测 40px，未见页面级横向溢出。
- 六种主题组合已在更新页留图；设置面板通过实际亮暗/品牌控件切换验证，根主题与本地持久化一致，浮层正文 opacity=1、宽520px。不宣称所有页面六主题全覆盖。一次测试调试连接无响应，终止该连接并加超时后同流程复跑通过，原因未确认，不归因于产品已修复。
