# Web 与 Tauri Client 状态及维护规范

> 基准日期：2026-08-30
> 适用范围：`web/` 共用 Vue 应用、`client/` Tauri 桌面壳和局域网更新体验。

## 当前结论

Web 与 Tauri 共用同一套业务页面、认证续期、权限判断和请求抽象。Windows 发布改为局域网完整包后，桌面端保留“更新前确认，确认后下载、校验、安装并重启”的流程；不再向用户展示公网发布源、差分、增量节省或自动降级语义。

Server 2016 负责构建、分发和运行服务端，不是日常 Web/Tauri 终端。Windows 10 用户在登录页填写 ERP 服务器局域网地址，登录、业务 API 和客户端更新共用该地址。

## 更新交互契约

- 更新中心使用“局域网发布源”“完整更新”文案，不出现 GitHub、Gitee Release、公网 manifest、增量、差分或降级提示。
- Web 浏览器只查看发布状态；服务端由计划任务自动升级和重启，不在页面提供普通的手动重启按钮。
- 管理员恢复 ZIP 仅作为故障恢复入口，并受 `system:updates:write` 控制。
- 桌面客户端点击“立即更新”后必须先显示确认；默认焦点落在“稍后处理”，避免回车误更新。
- 自动更新固定使用已确认的 Portable 单 EXE 完成原位备份、替换、启动验证和失败回滚；NSIS 只用于首次安装或人工恢复。
- 更新步骤固定为检查、下载、校验、安装、重启。Applying/Restarting 阶段不能通过遮罩、Esc 或关闭按钮退出。
- 检查失败提示核对服务器地址、同一局域网、防火墙私网放行和服务端运行；制品缺失提示管理员检查服务器计划任务和发布日志。
- 下载、校验或安装失败保留当前版本并提供“重试更新”；仅检查失败使用“重新检查”。
- 成功、警告和失败状态同时显示文字，不能只依赖颜色；动态区域保留 `aria-live`、`aria-busy`、焦点回收和可访问名称。

## 服务器地址契约

- 字段统一称“ERP 服务器地址”，示例 `http://192.168.1.20:8080`。
- 地址表示运行 Go 服务端的 Server 2016 或 Windows 10 局域网电脑；当前方案不宣传公网扩展。
- 测试成功表示 ERP 服务和局域网更新源可访问；失败信息必须包含 IP、端口、局域网、防火墙和服务状态的排查方向。
- 保存不同地址后强制重新登录，清除旧地址对应的桌面更新状态，并重新检查。

## 维护规则

- Web 请求只依赖 `HttpTransport`，组件内不新增平台专属网络实现。
- 版本、EXE 哈希、签名、更新计划、本机路径和安装替换属于 Rust/Tauri；Vue 只触发并展示状态。
- 更新状态使用现有 Element Plus Alert、Tag、Progress、Dialog、Steps 和 Button，不新增平行状态组件或硬编码颜色。
- 修改共用 Vue 源码后同时执行 Web 与 Client 构建；修改 Rust 更新代码后执行 fmt、locked check 和 locked tests。
- API 或发布协议变化同步 `docs/API.md`、`client/API_SYNC.md`、本文档和架构图。

## 验收尺寸与权限

- 320、390、768、920、1280px 以及 200% 缩放下无横向滚动、文字截断或按钮遮挡。
- 只读账号看不到重新校验和恢复包下载入口，但能看到状态及“联系系统管理员”的下一步。
- 仅键盘可完成服务器配置、重新检查、稍后处理、确认更新和失败重试。
- 关闭颜色后仍能通过文字判断状态；动态进度不高频重复播报字节变化。
